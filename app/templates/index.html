Free & open · any taxon

Build a phylogenetic tree from any species list.

phylogen fetches sequences from GenBank, aligns them (MAFFT), trims the alignment (trimAl), and gives you an instant Neighbor-Joining preview tree — with an optional bootstrapped Maximum-Likelihood tree (RAxML-NG) on request. Works for animals, plants, fungi, bacteria — any group NCBI has sequence data for.

Before you start — you'll need two free API keys

  • An NCBI contact email (and optionally a free NCBI API key, which raises the fetch rate limit). NCBI requires an email on every Entrez request; this is not a login.
  • A free usegalaxy.eu account API key (Galaxy → User → Preferences → Manage API Key) — alignment, trimming, and the optional ML tree run as jobs on your Galaxy account.

Nothing you enter is stored on this server or in a database — your keys are held in memory only for as long as your job's pipeline needs them, then discarded. There is no login for this site; a browser cookie just remembers which jobs are yours so they show up below.
